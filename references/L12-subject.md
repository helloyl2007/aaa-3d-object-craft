# L12 Studio 展示（单体专用）

> 目标：**一次只做一个高质量单体**——角色、道具、器械、器物。不做场景编排，不按对象类路由。
> 本层只保留 studio 展示模式：三点光 + 转台 + 三档距离 + 近景。建模走自由建模，烘焙走「基座固定、配方自由」；两者不在这里预设。

---

## L12.4 studio 验收范式（单体专用）

单体靠**打光审视**，不靠场景氛围。固定配置：

```js
// 背景：CSS 径向渐变 + alpha 画布（无 HDRI、无雾）
// 光：key(45°上，2.4) + fill(反侧，.7，冷) + rim(后方，1.5) + hemi(.32)
// 台面：圆柱平台（半径 1.35，深灰 rough .82），接收阴影；可勾选隐藏（纯剪影验收）
// 转台：group.rotation.y += dt * .25（可勾选关闭）
// 相机：fov 40；三档距离 = 1.2H / 1.9H / 3.4H（H = 归一化最大尺寸）；lookAt (0, .5H, 0)
// 交互：左键拖动环绕（yaw/pitch 阻尼，pitch 限 -.28~1.15）、滚轮缩放（dist .9~6.5）
```

**交互纪律**：拖动/滚轮只改相机，不重置转台角度；切换单体只刷新机位高亮（`markDist`），不打断用户当前视角；转台自转与台面显隐用复选框控制——**关自转便于同角度三档对比，隐藏台面便于纯剪影验收**（连接触阴影一起消失，只留背景渐变）。

**三档距离验收**（每档各截图一次）：

| 档位 | 看什么 | 不合格表现 |
|---|---|---|
| 近（1.2H） | 微结构、AO、磨损五层、倒角 | 表面干净、缝是画的 |
| 中（1.9H） | 比例、部件过渡、材质层次 | 比例失真、像拼装玩具 |
| 远（3.4H） | **剪影可读性** | 剪影和常见物体混淆 = 造型失败 |

**必查**：UV 拉伸（大件贴 logo/条纹处）、法线接缝、发光件是否过曝、接触阴影是否落地。
